# Retired EaseVerse Companion source

This directory is a temporary read-only source archive. It has no package,
release workflow, production pairing endpoint, or supported run command.

The only supported desktop integration is **CreatorHub Pro Tools Companion**
in `creaotrhubn26/Creatorhubn-monorepo`. Users install and pair it from:

```text
CreatorHub Workspace → music project → Sound Room → Pro Tools Companion
```

Do not copy features into this archive. Implement parsers, watcher behavior,
authentication and releases in the canonical CreatorHub app.
